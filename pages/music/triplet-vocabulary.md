# Triplet Vocabulary

These nine two-triplet melodies come from the vocabulary approach taught by [JP Bouvet Method](https://jpbouvetmethod.com/). `A` and `B` are abstract roles rather than fixed limbs or instruments. An `A` can be assigned to a hand, foot, voice, or orchestration; `B` fills the remaining subdivisions.

In these first practice loops, every `A` is an ordinary snare stroke and every `B` is heard as a quiet ghost stroke. The staff prints only the reduced `A` melody, using longer notes and the minimum necessary rests instead of displaying the ghosted subdivisions. Because every printed note has the same role, none receives a redundant accent mark. Each six-subdivision melody is written twice to fill one bar of 4/4. The source uses `_` for the audible-but-unprinted practice strokes.

## Melody 1 — A B B · A B B

The first subdivision of each triplet carries the melody. One possible sticking is `R L L · R L L`, with full right-hand strokes and ghosted left-hand strokes.

```drums
tempo 100
meter 4/4
division 12
sn: x _ _ x _ _ | x _ _ x _ _
```
