# Math notation

Use a `math` fence for a two-dimensional mathematical expression. The source is ordinary LaTeX-style notation and remains readable in the Markdown file.

**Quadratic formula**

```math
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
```

**Sum of integers**

```math
\sum_{k=a}^{b} k
```

**Sum of squares**

```math
\sum_{k=a}^{b} k^2
```

**Pi series**

```math
\sum_{\substack{i=1 \\ \text{by }4}}^{\infty}\frac{1}{i(i+2)} = \frac{\pi}{8}
```

Open Source beneath an expression to copy or inspect the original notation.
