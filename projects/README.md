# Standalone projects

These projects are static applications deployed alongside the wiki. Each project owns its HTML, CSS, JavaScript, and runtime state, and must work when opened directly under the GitHub Pages project subpath.

- `piano/` — MIDI-first music-reading trainer rendered with VexFlow.
- `euclidean-rhythm-explorer/` — drum tracks built from Euclidean patterns and Boolean operations.
- `rhythm-explorer/` — editable, generative drum-pattern explorer with notation, playback, and a compact round-trip rhythm language documented in `RHYTHM-LANGUAGE.md`.
